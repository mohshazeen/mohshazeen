Selected Projects
1. PAX IM30 Card Payment & Device Integration
React Native · Kotlin · Android USB Host · PAX IM30 ECR Protocol · REST APIs
An Android payment application connecting a card terminal with a downstream automated workflow.
- Integrated a React Native Android app with native Kotlin code for USB communication with the PAX IM30 terminal.
- Implemented terminal availability checks, ECR communication, payment processing, and transaction-result handling.
- Correlated application orders and payment transactions using transaction identifiers and middleware callbacks.
- Added timeout, cancellation, and payment-recovery handling to improve transaction reliability.
- Connected successful payment events to the next step in the device workflow.
2. Dialog Genie QR Payment & Digital Receipt System
React Native · Android · Node.js · Express.js · MongoDB · Dialog Genie · REST APIs
An Android payment application and backend flow for QR payments, transaction verification, and digital receipts.
- Integrated Dialog Genie QR payments with backend APIs for payment processing and transaction tracking.
- Verified payment status before allowing the application workflow to continue.
- Built digital receipts with QR-code access, secure receipt links, and SMS receipt delivery.
- Developed a mobile interface for payment amounts, transaction details, payment status, and receipt information.
- Connected middleware callbacks with transaction records and automated workflow handling.
3. MyPetShop.lk — Pet Marketplace
MongoDB · Express.js · React.js · Node.js · Tailwind CSS · PayHere · SMS Gateway · Cloudinary
A full-stack marketplace connecting pet buyers and sellers across Sri Lanka.
- Built responsive public and admin dashboards backed by REST APIs.
- Implemented user authentication, SMS OTP verification, advertisement posting, moderation, and approval workflows.
- Integrated PayHere for payments and Cloudinary for advertisement image management.
- Developed search and filtering, seller profiles, category management, ad expiry, and related advertisements.
- Implemented administration features for users, advertisements, categories, analytics, and marketplace operations.
4. HR & Payroll Management System
MongoDB · Express.js · React.js · Node.js · Tailwind CSS · JWT · PDF Generation · Email Integration
A private business system supporting employee administration, leave management, monthly payroll processing, and reporting. Demo available on request.
- Built secure authentication and role-based access control.
- Developed a staff self-service portal for leave applications, leave history, and entitlement tracking.
- Implemented employee, salary, department, designation, and employment-record management.
- Added payroll calculations for allowances, bonuses, commissions, deductions, and no-pay leave.
- Automated payslip PDF generation, email delivery, payroll history, approvals, and finalization.
